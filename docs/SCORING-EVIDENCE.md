# 评分点与可核验依据

| 评分点 | 可现场核验的真实证据 |
| --- | --- |
| 三角色与权限 | 分别登录 `admin`、`teacher01`、`student01`；学生请求管理员资源返回 403。 |
| 学生与教职工管理 | 管理员页面创建、检索、冻结、重置密码；冻结后旧 JWT 立刻失效，再次登录被拒绝。 |
| 课程与选课 | 教师创建课程后发布；学生端只显示已发布课程；容量、重复选课与已提交成绩后的退课均由后端校验。 |
| 成绩闭环 | 教师保存草稿并提交，管理员审核或退回，发布后学生才能查询成绩。 |
| 学分与 GPA | 通过 `GET /api/grades/mine` 读取成绩、学分和 GPA；重复发布前后数值保持一致。 |
| ECharts 看板 | 首页柱状/分布图直接使用 `/api/dashboard` 的数据库统计数据；无静态模拟统计。 |
| Redis | 后端 dashboard 的 `cache` 字段显示真实连接、命中与 TTL；不可用时明确报告 DOWN。 |
| 实时通知 | 浏览器使用带 Authorization 的 fetch 流订阅 `/api/events`；服务端发送 notification、refresh、heartbeat 事件。 |
| 天气 | `/api/weather` 由后端请求 Open-Meteo；超时或失败时返回 `available=false` 和原因，不以假数据代替。 |
| 多媒体与导入导出 | 上传图片/视频后在资料区预览；学生模板下载、Excel 导入和脱敏导出均走受认证的后端接口。 |

完整的跨角色顺序请运行 `scripts/test-smoke.ps1`，其断言覆盖选退重选、成绩退回再提、发布幂等性、学生与教师越权、冻结 JWT 失效。答辩时保留该脚本的成功输出，作为可重复的验证证据。
